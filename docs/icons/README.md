# Icons

Used by [`../tools/diagrams.py`](../tools/diagrams.py), which inlines them into
`docs/architecture.svg` and `docs/k8s-components.svg`. Nothing is loaded at view time.

| Folder | Source | Licence |
|---|---|---|
| `brands/` | [Simple Icons](https://simpleicons.org) 13.21.0, recoloured with each brand's official hex | CC0 1.0 |
| `k8s/` | [Kubernetes icon set](https://github.com/kubernetes/community/tree/master/icons) | Apache-2.0 or CC-BY-4.0 |

Logos are trademarks of their owners and appear only to identify the technology that each part
of the system uses. The Kubernetes logo is a registered trademark of The Linux Foundation.

NFS, flannel, CoreDNS and metrics-server have no icon in either set. The generator draws small
generic glyphs for them instead.
